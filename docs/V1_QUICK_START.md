## 1. 启动、暂停与正常退出

在获准的隔离环境中，将 Release 便携 ZIP 完整解压到可写的新目录，保留 `panebind.exe`、`portable.flag`、许可证及说明。双击 `panebind.exe`，不需要附加启动参数；程序打开中文设置，不创建控制台。再次启动同一程序会请求打开原实例的设置，不应安装第二套增强。不要同时运行多个目录中的不同版本。

正式产品要求普通权限、同用户和同交互会话；不要选择“以管理员身份运行”。旧 High Sandbox 自动测试例外不等于普通产品支持高权限窗口，也不授予宿主试用许可。

设置上方的固定运行条显示实际“运行中”“已暂停”或“输入故障”。

- **立即暂停／立即恢复**：立即改变运行状态，不保存其它页面的草稿。取消设置不会回滚已经执行的暂停或恢复。输入故障时先查看诊断，不把按钮文字当成已恢复健康的证据。
- **帮助**：显示当前有效映射与基本操作。未保存的映射草稿不会冒充当前有效快捷键。
- **退出程序**：正常退出 PaneBind。若有未保存修改，选择“返回设置”继续编辑，或“放弃修改并退出”；默认返回，不自动保存草稿。
- 设置右上角 **×**、底部 **取消** 或设置中的 `Esc`：只关闭设置并放弃草稿，后台程序仍运行，**不等于退出程序**。

`Ctrl+Shift+F11` 为保留的紧急暂停键，用来停止当前增强；之后可重新打开设置并恢复。手势中的 `Esc` 取消当前增强，仅在身份和上下文仍有效时尝试恢复本次起点。不要用强杀进程或销毁 guest 代替正常退出。

当前托盘实际可达性仍有独立验收缺口；新增运行条不代表托盘已通过。在已有实例运行时，可再次双击 EXE 打开设置。必要时也可从包目录请求：

```powershell
.\panebind.exe --settings
.\panebind.exe --status
.\panebind.exe --pause
.\panebind.exe --quit
```

这些命令分别请求设置、写入状态、暂停和退出；请求发送成功不等于清理已完成。普通图形使用不需要打开命令行。

## 2. 磁吸、Ctrl 联动、停靠与拉伸

- **普通移动**：在合格标题栏按住左键拖动。接近其它合格窗口或工作区边缘时磁吸，继续拉开可脱离，再靠近可重吸。默认吸引距离 10 DIP、释放距离 16 DIP。
- **Ctrl 联动**：在按下鼠标前按住 `Ctrl`，从任意邻接成员起手移动本次连通组。只有角点相碰不算邻接，没有永久 Leader。共享边上的 Ctrl 缩放调整相关成员，仍受应用尺寸约束。
- **Shift 绕过**：普通拖动起手前按住 `Shift`，本次使用原生操作；`Ctrl+Shift` 起手同样优先绕过。起手后改变修饰键不重选当前模式。明确配置的 Shift 双击动作保留其映射。
- **普通缩放**：拖动窗口边或角；启用缩放磁吸时只修正活动边。应用的最小／最大尺寸及自定义约束可能限制结果。
- **停靠**：普通 Move 到屏幕边角可显示预览，移开取消，正常松键提交。默认左右半屏、顶部最大化、底部下半屏、四角四分屏；可在“停靠／拉伸”页改变方向动作。撤销布局使用下表快捷键。
- **拉伸**：默认双击单边向该方向拉伸；Shift 双击边沿同轴双向拉伸。角双击按当前映射处理。智能拉伸开启时参考相交邻窗，关闭时使用工作区边缘；不通过挪动其它窗口挤出空间。

Windows 自有 `Win+方向键` 保持原有映射。以下为 PaneBind 默认键位，修改后以设置列表及当前有效帮助为准。

| 快捷键 | 动作 |
| --- | --- |
| Ctrl+Alt+左／右 | 左／右半屏 |
| Ctrl+Alt+上／下 | 最大化／下半屏 |
| Ctrl+Alt+C | 居中 |
| Ctrl+Alt+R | 恢复 |
| Ctrl+Alt+U | 撤销布局 |
| Ctrl+Alt+T | 切换置顶 |
| Ctrl+Alt+N | 移到最近相邻显示器 |
| Ctrl+Shift+F11 | 紧急暂停，不能改作其它动作 |

上述为产品交互说明；具体应用、普通权限、跨屏与混合 DPI 的实际通过范围仍以验收表为准，不由 owned 演示外推。

## 3. 六页设置与草稿

| 页面 | 主要选项 |
| --- | --- |
| 常规 | 启用增强、用户登录后启动、设置窗口淡入 |
| 磁吸／联动 | 移动／缩放磁吸、Ctrl 联动及距离、速度、邻接参数 |
| 停靠／拉伸 | 方向动作、智能停靠／拉伸、预览颜色及不透明度 |
| 快捷键／鼠标 | 中文键盘列表、鼠标列表、添加／编辑／删除及步长 |
| 应用规则 | 程序／窗口类／规则列表及图形编辑表单 |
| 诊断／外观 | 关系提示、拖动透明、摇动参数与诊断 |

`Tab`／`Shift+Tab` 移动焦点，`Ctrl+Tab`／`Ctrl+Shift+Tab` 切换页面；页签取得焦点时可使用方向键。小窗口可滚动页面，焦点进入控件时页面应滚到可见位置。表单中“确定”只确认这一行到草稿，“取消”不修改这一行；切页保留草稿。

- **保存并关闭**：经校验、真实热键注册和原保存通路成功后才应用。
- **取消／×**：放弃未保存草稿，保留运行配置及已执行的即时暂停／恢复。
- **此页默认**：只恢复当前页，不丢其它页草稿；**全部默认**改变全部草稿，仍需保存才生效。
- **导入…**：读取完整 `.conf` 到草稿，不立即应用；取消设置可放弃导入。
- **导出…**：导出当前经过校验的草稿，不应用它，也不替代“保存并关闭”。

释放距离必须严格大于吸引距离；非法数值、重复条目或真实热键注册冲突会拒绝保存并保留原有效配置。登录启动默认关闭，只在获准环境内明确选择并保存后创建自己的用户级入口。

### 修改键盘快捷键

进入“快捷键／鼠标”的“键盘快捷键”列表，选择一行后点“编辑”，或双击该行。勾选 `Ctrl`、`Alt`、`Shift`、`Win`，从友好名称下拉框选择主键和执行动作，再点“确定”。

例如把“居中”从 `Ctrl+Alt+C` 改成 `Ctrl+Alt+J`：编辑“居中”行，将主键改成 `J`，保留 Ctrl、Alt，然后“确定”→“保存并关闭”。之后才使用新组合。取消表单不改原行；删除一行即取消该映射。F12 和 Ctrl+Shift+F11 是保留组合，不能保存；重复组合会指出冲突条目。已有合法非常用按键仍保留在编辑选项中。

### 修改鼠标操作

在同页的“鼠标操作”列表点“添加”。选择标题栏／边／角、左／右／中／侧键、单击／双击、修饰键及中文动作，再点“确定”。例如“标题栏／中键／单击／Ctrl／居中”。保存后才生效；删除并保存后取消该映射。未映射按钮及客户区默认透传，系统关闭／最小化按钮不作为标题栏映射区域。

### 管理应用规则

进入“应用规则”，点“添加程序…”。可直接输入程序名或含中文、空格的完整路径，也可点“选择 .exe…”选择文件；窗口类名可留空。无需自行转义路径。

新规则默认“排除此应用”。若选“自定义功能”，使用六个复选框选择磁吸、联动、停靠、拉伸、窗口命令和视觉效果；新自定义规则默认全部允许。各项仍受全局开关控制，停靠／拉伸等快捷命令还需要“窗口命令”许可。切换模式保留当前勾选，编辑旧规则不会清除未知功能位。

也可先切换到目标应用，再重新打开设置，点“添加当前应用”；程序沿原通路重新核验打开设置前的目标身份，不按标题猜测应用。相同程序与类名的重复规则会被拒绝。删除选中规则并保存即可取消该条规则，不影响其它规则。

### 选择预览颜色

在“停靠／拉伸”页查看色块，点“选择颜色…”使用系统颜色选择器，或直接填写 `#RRGGBB`，例如默认蓝色 `#0078D7`。取消颜色选择不改草稿，格式不正确不能保存。保存后的颜色用于下一次预览；不透明度仍在 1–255 范围。普通用户无需换算颜色整数。

## 4. 文件、诊断与实际限制

便携模式保留 EXE 同目录的 `portable.flag`，配置使用同目录 `settings.ini`；没有该标记时使用当前用户 `%LOCALAPPDATA%\PaneBind\settings.ini`。损坏配置会留存为 `settings.ini.corrupt.<时间>` 再使用默认值；无法备份时不应静默覆盖原文件。正常运行时不要用外部编辑器同时改写配置。

设置底部“诊断”可导出 `diagnostic-*.txt` 到配置目录，不保存草稿。有限轮转日志为 `panebind.log.jsonl`。报告问题时提供实际包身份和操作顺序，保留日志；不要上传用户文档、私钥或无关文件。

本轮暂缓 100%／200%、独立双屏／负工作区／混合 DPI、真实虚拟桌面／锁屏／休眠、原生 Shake 共存、无新依据的真实应用初始化、相同托盘前置和 NF02 慢尾专项，由产品经理统一安排后续攻坚。暂缓不等于通过；真实应用、托盘和整版门槛仍然保留。演示只覆盖其实际检查的自有测试窗，不是五应用兼容或真人 UAT。
